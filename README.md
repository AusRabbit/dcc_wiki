# Dungeon Crawler Carl — Campaign Wiki

Generated from the session recordings. Same pipeline as the Star Wars wikis,
with a floor axis on top.

## How it works

```
Craig recording -> faster-whisper -> transcript.txt -> content/*.md -> docs/index.html
```

`content/` is an Obsidian vault: one markdown file per entity, `[[wikilinks]]`
between them. `build.py` turns it into a single self-contained HTML page in
`docs/`. Standard library only:

```bash
python build.py
```

It exits non-zero on any `[[wikilink]]` pointing at a page that doesn't exist,
and renders those links red on the site.

**`docs/index.html` is committed.** Edit markdown without running `build.py`
and the published site won't change.

## Floors

This campaign has a second axis the Star Wars ones don't: every page can carry
a `floor`, and the floor's own page assembles a list of everything tagged to it.
Tag a mob `floor: 3` and it appears on Floor 3 without anyone maintaining an
index.

`Pre-Collapse` and `Surface` are floors in this scheme — the prologue.

## config.json

Everything campaign-specific lives here: the sidebar groups, the type labels,
the floor axis and its ordering, and the status vocabulary. `build.py` itself is
generic, so the same file can run any campaign. A repo with no `config.json`
falls back to the original Star Wars defaults.

## Frontmatter

```yaml
---
title: "Dale Prosky"
group: "Bestiary"        # a group from config.json
type: mob                # crawler | rival | npc | production | mob
                         # place | item | quest | rule | floor | doc
floor: "Surface"         # which floor this belongs to
status: dead             # active | dead | destroyed | escaped | retired | unknown
conf: hi                 # hi | mid | lo — confidence in the name
short: "Dale"            # optional: the form people actually say
aliases: ["Drunk Dickwad Stair Bully"]
dek: "One line under the title."
---
```

## The two name files

Regenerated by every build. They do opposite jobs:

- **`names.txt`** — canonical spellings only, prompted *into* the transcriber so
  it biases towards the right words. Never add a misspelling here.
- **`corrections.json`** — alias → spoken form, applied to the transcript *after*
  recognition. Targets what people say (`Frankie` → `Frank`), not the formal
  title.

Mechanics and floor pages are excluded from `names.txt` — "Combat" is not a
proper noun and would waste the prompt budget.

## What's not here

GM notes. Anything the players haven't discovered, and anything said at the
table that wasn't in character. `.gitignore` excludes `gm/`.
